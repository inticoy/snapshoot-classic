# 5단계: 등번호 · 이름 · 얼굴

## 목표
- 유니폼 등에 **등번호(큰 숫자) + 이름**, 가슴 작은 번호. 현재 유니폼은 `SkinnedPlayerModel.ts`의 셰이더가 바인드 포즈 좌표로 칠한다 → 등/가슴 영역에 캔버스 텍스처(선수별 번호·이름) 데칼을 셰이더에서 투영(바인드 포즈 xz/yz 평면 투영). 팀 폰트/색 대비 확보.
- **얼굴**: 마네킹 머리에 눈·눈썹·입 정도의 간단한 얼굴 텍스처(선수별 피부톤과 조합), 머리 스타일 2~4종(셰이더 영역 or 간단 메시), 수염 옵션. 과하게 사실적일 필요 없음, FC 계열 원거리 중계 화면에서 구분되는 수준.
- 팀 유니폼 디자인 변형(줄무늬/어깨 라인)과 키퍼 유니폼 구분.
- 절차적 모델(PlayerModel, 대체용)에도 번호 유지.

## 완료 조건
- Playwright 근접 스크린샷으로 등번호·이름·얼굴 확인 이미지를 `docs/screenshots/`에 저장
- 22명에서 성능 회귀 없음, `pnpm typecheck && pnpm test && pnpm build` 통과, 커밋 (푸시 금지)

## 참고: 브라우저 검증
Codex 샌드박스에서는 Chrome 실행이 막힌다(SIGABRT/EPERM). Playwright 스크립트는 `scripts/`에 작성만 하고, 실행이 막히면 재시도하지 말고 "미실행"으로 보고한다. 검증은 vitest 시뮬레이션 테스트로 대신한다. 브라우저 실행은 사람이 검토 단계에서 한다.
