# 0단계 구현·검증 기록

검증 날짜: 2026-10-16

## 구현

- Vitest Node 환경에서 실제 `Match.update`와 cannon-es 물리를 실행한다. 선수 모델 팩토리를 주입해 캔버스·document·GLTF 로드 없이 경기를 만든다.
- 경기별 `Random(seed)`의 균등·정규 난수로 AI, 킥 오차, 태클, 트래핑, 선방을 재현한다. 화면·애니메이션·관중·사운드는 별도 연출 난수원을 사용한다.
- AI 공격수 움직임의 벽시계 의존을 고정 스텝 누적 시간으로 바꿨다. 이동의 진폭과 주기는 유지하며 일시정지 중에는 경기 시간이 흐르지 않는다.
- 기본 생성 옵션은 기존 선수 모델 선택과 사용자 조작을 유지한다. 테스트에서는 골망 시각 갱신만 생략할 수 있고 골대·그물 충돌체는 동일하다.
- 배포 워크플로는 빌드 전에 타입 검사와 테스트를 통과해야 한다.
- 한국어 설명, OG/Twitter 공유 정보, 공 모양 SVG 파비콘, Apple 아이콘, 매니페스트와 192/512px 아이콘을 추가했다.
- `public/og-image.png`는 기존 작업 폴더의 실제 플레이 캡처(`sp/live-play.png`, 2026-10-16)를 비율을 유지해 1200×630으로 만든 이미지다. 이번 변경의 브라우저 캡처는 실행 환경 제한으로 생성하지 못했다.

## 미완료 조건과 한계

- 개발 서버 브라우저 검증은 미완료다. Playwright의 캐시된 Chrome for Testing 실행이 SIGABRT/EPERM으로 종료됐다. 대체 Chrome 컴퓨터 제어는 도구에서 `Computer Use was not approved to use Google Chrome`으로 거부됐다.
- 사람의 검토 환경에서 `pnpm dev` 후 `pnpm test:browser`를 실행하면 메뉴 → 경기 시작 → 일시정지/재개 → D 키 슛 → 골을 검사한다. 스크립트는 작성·구문 검사했으며 브라우저 실행 결과는 없다. 생성 캡처는 `.artifacts/browser-smoke/`에 저장한다. 필요하면 `CHROMIUM_PATH`로 Chrome for Testing을 지정한다.
- `pnpm test:browser --update-og`는 브라우저 검증 시 1200×630 경기 화면으로 공유 이미지를 갱신한다. 득점 확인에는 고정 시드·골문 앞 선수 배치를 사용하며 득점 수치를 직접 변경하지 않는다.
- 커밋은 미완료다. 의미 단위 커밋을 위한 첫 `git add`가 `.git/index.lock: Operation not permitted`로 실패했다. 현재 환경은 `.git` 읽기만 허용하므로 스테이징·커밋을 진행할 수 없다. git push는 실행하지 않았다.
- 예정한 커밋 단위는 (1) 고정 시드 시뮬레이션·회귀 테스트·배포 검사·브라우저 확인 스크립트, (2) 공유 메타정보·아이콘·메타정보 테스트, (3) README·체크리스트·검증 기록이다. 각 커밋 메시지 마지막에는 `Co-Authored-By: Codex <noreply@openai.com>`을 넣는다.
- 이번 작업 중 별도로 수정된 `phase-1.md`~`phase-5.md`는 수정·커밋 대상에 포함하지 않았다.
- 패스·받기·슛 성공률은 정해진 시드와 격리된 상황에서 측정했다. 압박·다양한 거리·모든 설정 조합의 실제 플레이 품질을 보장하는 수치는 아니다. 실제 프리셋의 패스/슛 재보정은 기존 후속 작업으로 남는다.
- 설정과 활성 물리 프리셋은 기존 전역 상태다. 다른 프리셋의 동시 경기와 브라우저/플랫폼 간 온라인 동기화용 결정성은 이번 단계에서 다루지 않았다.
- 빌드의 JS 청크는 810.93kB (gzip 222.09kB)로 Vite의 500kB 권고 경고가 남는다. 빌드는 성공하며 코드 분할은 이번 범위에서 변경하지 않았다.

브라우저 확인과 커밋 조건이 남아 있어 0단계 전체를 완료로 판정하지 않았다. 구현·자동 검증이 끝난 항목만 체크리스트에 완료로 표시했다.
