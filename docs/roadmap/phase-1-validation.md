# 1단계 구현·검증 기록

검증 날짜: 2026-10-16

## 구현

- `Input`에 포인터별 가상 버튼 소스와 아날로그 축을 추가했다. 키보드와 터치가 같은 `ButtonState` → `UserCommand` → `Match.update` 경로를 사용한다. 마지막 입력 소스가 해제될 때만 release가 생기고, 고정 스텝 사이의 짧은 탭도 보존한다.
- `TouchInput`은 조이스틱 데드존·길이 제한, 여러 손가락, 슛 위 스와이프 칩슛·좌우 스와이프 감아차기를 처리한다. 스와이프 보조키는 release를 처리하는 고정 스텝까지 유지한다.
- 공격은 슛·패스·스루·로빙·질주, 수비는 압박·선수 변경·스탠딩 태클·슬라이딩·질주·동료 압박·견제다. 공격 판정은 기존 경기 로직을 추출해 재사용하며 세트피스는 짧은/긴 스로인·크로스·롱킥을 표시한다.
- 포인터 캡처로 버튼 밖 release를 받는다. 취소·예기치 않은 캡처 해제·회전·탭 이탈·메뉴 전환에서 터치 입력과 차지/원터치 예약을 정리한다. 공격/수비 전환에서는 이동·질주를 유지하고 의미가 바뀌는 버튼은 취소한다.
- coarse 미디어 쿼리 또는 첫 터치 포인터로 터치 UI를 켠다. 세로 화면에는 가로 회전 안내를 표시하고 진행 중 경기를 일시정지한다. 경기 중 터치 일시정지와 메뉴 뒤로가기로 재개할 수 있다.
- 메뉴 좌우 변경은 각각 최소 44×44px 버튼이다. 터치 pointerenter가 메뉴를 다시 그려 클릭 대상을 잃는 경우를 막았다. 기존 키보드 메뉴 조작도 유지한다.
- 터치에서는 키 안내를 숨기고, 선수 바를 상단에, 축소 레이더를 중앙 하단에 배치한다. 오른쪽 버튼은 안전 영역 여백을 사용한다.
- 그래픽 자동/낮음/높음을 저장한다. 자동은 터치 또는 CPU 4코어 이하에서 낮음이다. 낮음은 DPR 최대 1.25, 그림자 1024×1024, 관중 25%; 높음은 DPR 최대 2, 그림자 2048×2048, 관중 100%다. 품질 변경은 즉시 반영한다.

## 모바일 브라우저 재검증

`pnpm test:mobile`을 한 번 실행했으나 캐시된 Chrome for Testing 시작 단계에서 SIGABRT, 프로세스 종료 처리에서 EPERM으로 차단됐다. 문서 지침대로 재시도하지 않았다. **브라우저 시나리오는 미실행이며 통과로 집계하지 않았다.**

검토 환경에서 다음을 실행한다.

```bash
pnpm dev --host 127.0.0.1
# 다른 터미널에서
pnpm test:mobile
pnpm test:browser
```

- `scripts/mobile-smoke.mjs`는 가로 844×390, `hasTouch: true`, DPR 3으로 실행한다. 메뉴 좌우 값 변경·경기 시작은 터치로, 조이스틱+슛 멀티터치는 CDP의 실제 터치 이벤트로 입력한다.
- 선수 이동 >0.2m → 차지 ≥0.35 → 슛 기록 1회 증가와 kick 이벤트를 검사한다. AI의 우연한 탈취를 막기 위한 선수 배치만 고정하며 이동·슛 기록은 직접 변경하지 않는다.
- 터치 UI·HUD 비겹침·낮음 그래픽 실제 적용·일시정지/재개·세로 회전 안내도 검사한다. 캡처는 `.artifacts/mobile-smoke/`에 저장한다.
- `scripts/chrome-path.mjs`를 기존 데스크톱 스크립트와 공유한다. 필요하면 `CHROMIUM_PATH`, `SNAPSHOOT_URL`로 실행 환경을 지정한다.

## 커밋과 남은 한계

- `git add`가 `.git/index.lock: Operation not permitted`로 실패했다. 현재 샌드박스는 `.git`을 읽기 전용으로 제공하고 권한 상승도 허용하지 않는다. 따라서 스테이징·커밋은 **미완료**이며 git push는 실행하지 않았다.
- 검토 환경의 커밋 단위: (1) 터치 입력/UI·그래픽 품질·51개 테스트·모바일/공통 브라우저 스크립트·의존성, (2) 체크리스트와 이 검증 기록. 각각 메시지 마지막에 `Co-Authored-By: Codex <noreply@openai.com>`을 넣는다.
- DOM 테스트는 실제 CSS 레이아웃, GPU 렌더링, 브라우저의 네이티브 포인터 캡처, iOS/Android 터치 감각을 보장하지 않는다. HUD 비겹침·기기별 안전 영역·화면 회전은 브라우저 및 실기기에서 확인해야 한다. 모바일 FPS와 발열은 측정하지 않았다.
- 기존 빌드 청크 경고가 남는다: JS 821.61kB, gzip 225.69kB (Vite 권고 500kB 초과). 빌드는 성공한다.
- 구현·자동 검증 항목은 체크리스트에 완료로 표시하고, 브라우저 실검증·커밋은 미완료로 분리했다. 1단계 전체 완료로 판정하지 않았다.
