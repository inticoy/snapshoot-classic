# 3단계 커맨드 구현·검증 결과

## 구현

- `INPUT.doubleTap = 0.25`초. 키보드 누름·뗌을 고정 스텝 시간으로 판정한다. 짧은 첫 입력은 첫 누름의 연타 창 종료까지 기다리고, 두 번째 누름은 대기 킥을 한 번만 승격한다. 길게 차지한 킥은 뗄 때 바로 기존 준비 동작으로 이어진다. 터치의 즉시 뗌 동작은 유지한다.
- SS·WW 딩크, Z+Q+W 낮은 로빙 스루, Q+S 짧은 침투 리드, 별 3 이상 C+S 플레어, 측면 A/AA/QA/CA/ZA 크로스. 크로스는 상대 골라인 30m 안·`|z| > boxWidth/2`에서 해석한다.
- DD 수평 파워 +10%·수직 0.65m/s·오차 18% 증가. ZDD 회전은 ZD의 35%. CD 및 플레어 패스는 오차 35% 증가와 실제 GLB 발목·허벅지·상체 오버레이를 적용한다.
- F를 누른 채 D 차지 → D를 떼면 0.4초 준비. 준비 시작 후 0.25~0.35초의 두 번째 D가 정확도 보너스를 받는다. 첫 타이밍 입력만 유효하며 미입력/이른 입력도 준비 종료 시 한 번 발사한다. 머리 위 HUD에 초록 창·커서·성공 표시를 추가했다.
- Space 유지 접근·상대 목표 속도 70%, 1.5초 초과 접촉은 `Rules.judgeTackle`로 반복 판정하며 장기 접촉 위험을 높인다. 기존 Space 첫 탭 스탠딩 태클은 유지한다. 가까운 자유 공 D는 즉시 높이 걷어내며, 소유자 옆 D 탭·C+방향은 몸싸움/밸런스로 0.3초 균형 상실을 판정한다. C+E 견제는 질주 속도 비율 0.95다.
- 대기 입력 취소·소유 상실·재시작, 원터치 예약의 보조키 보존을 검증했다. `TeamAI.ts`와 기존 물리 프리셋·보정 설정은 변경하지 않았다.

## 재현 방법과 측정 정의

```bash
pnpm install
pnpm typecheck
pnpm test
pnpm build
pnpm exec vite-node scripts/stage3-measure.ts --report
```

`playground/scripts/stage3/*.json` 26개를 `runScript`로 실행한다. 각 JSON은 실제 `KeyS/KeyD/KeyF` 등의 누름·뗌 엣지를 `Input` → `scriptCommand` → `Match.update` → 물리 루프에 전달한다. 시드 0~19, 각 4초(접촉 3.5초), 120Hz, 기본 arcade/assisted 기준이다. 총 520회 재생이며 킥/접촉 커맨드 실행은 520/520회다. 원자료는 [stage3-measurements.json](stage3-measurements.json).

초속은 발사 순간 전체 속도이며 괄호는 수평 속도다. **딩크 0.9배·DD +10%는 수평 속도 기준**이다. 최고 높이는 발사 후 첫 지면 접촉/몸 충돌/선방/소유 획득 이전의 공 중심 높이 평균이다. 수신자·완료는 실제 소유권으로 측정하며, 슛은 득점률을 따로 쓴다. 커맨드 인식률과 득점률을 혼동하지 않는다.

S/SS/W/WW는 15m 앞 동료와 4m 앞·옆 0.65m의 수비수 배치다. 의도적으로 S/W의 발 인터셉트를 유발해 딩크 차이를 검사한다. QW/ZQW/QS/CS는 수비 없는 동일 거리 배치, 크로스는 (35,24)에서 박스 안 동료와 오프사이드 라인을 만드는 수비수 배치다. 슛은 22m 앞 키퍼 배치이며 아주 짧은 탭, F는 0.4초 차지다. 이 표는 11대11 경기 승률이나 전술적 성공률을 의미하지 않는다.

## 검증 결과

- `pnpm install`: 통과, 잠금 파일 변경 없음.
- `pnpm typecheck`: 통과.
- `pnpm test`: **32개 파일, 425/425개 통과**, 89.63초, 미처리 오류 0개. 긴 기존 AI 회귀가 Vitest RPC 보고를 막는 문제는 경기 사이 `setImmediate` 양보로 해결했다. 경기 수·시간·측정 계산·기대값은 그대로다. 커맨드 59개 + HUD/실제 GLB 2개 추가, 기존 플레이그라운드 검사에도 새 시나리오 5개를 포함했다. 기존 기대값은 낮추지 않았다.
- `pnpm build`: 통과(1.62초). Vite의 기존 500kB 초과 청크 경고는 남아 있다.
- JSON 26개 × 20시드 = 520회 측정 완료.
- `git diff --check`: 통과.
- 브라우저: `pnpm test:playground`의 캐시 Chrome for Testing 실행이 SIGABRT로 실패했다. 연결 브라우저의 localhost 접근도 보안 정책으로 거부되어 WebGL 화면·실시간 조작 확인은 미완료다. 우회 접근은 시도하지 않았다. Happy DOM은 실제 HUD 클래스·초록 창 위치·커서·성공 표시·머리 위 좌표를, 실제 GLB 검사는 세 관절 회전 차이를 확인한다. 이를 브라우저 화면 검사로 간주하지 않는다.
