# 터치 드리블 튜닝 측정 결과

## 측정 방법

- 사용자: `tests/dribble-play.test.ts`, 시드 0~29의 킥오프 뒤 앞 2초 → 뒤 2초 → 위 1.5초 → 아래 1.5초 → 앞+질주 2초. 기존 기대값을 그대로 유지했다.
- AI: `tests/dribble-ai.test.ts`, 시드 0~9, 경기 길이 300초, 각 시뮬레이션을 고정 스텝으로 300초씩 진행한다. `kickMotion: true`, `userControl: false`에서 `dribbleTouches: false/true`를 비교한다.
- 전진 속도는 playing 중 필드 소유자의 공격 방향 실제 이동 합계 / 해당 소유 시간이다. 슛·헤비 터치는 10경기 합계다. 추격 시간은 같은 소유 시간 중 발끝(`pos + facing * 0.35`)에서 공이 수평 거리 0.75m를 넘는 비율이며, 킥 준비 시간도 제외하지 않는다.
- 변경 전은 작업 시작 시점 `02d6ece`의 코드를 같은 테스트로 측정했다. 지시서의 대략적인 AI 수치 대신 같은 측정 코드에서 얻은 값을 비교한다.

## 선택한 구현

- 발 도달 거리·회전 터치 거리는 0.95m, 회전 감지 각도는 0.3rad로 조정했다. 거리 확장만으로는 AI 전진 1.56m/s, 추격 53.7%여서 충분하지 않았다.
- 의도와 공 방향이 0.6rad 넘게 어긋나고 발끝 거리 0.7~1.2m이면 몸을 공 쪽으로 돌려 발을 뻗는다. 이동 입력은 계속 reach 밖에서만 공 쪽으로 보정한다.
- AI는 이전 드리블 방향을 50% 섞고, 소유를 잃으면 기억을 지운다. 예전 붙임 드리블 비교 모드는 기존 AI 방향을 유지한다.
- 터치 목표는 다음 발 디딤 앞으로 잡고 현재 공의 앞·옆 간격을 뺀다. 기존처럼 매번 같은 방향으로 속도를 더하면 공과 나란히 달리거나 간격이 누적됐다. 첫 터치에도 같은 원칙을 적용하자 추격 시간이 17.33%에서 9.43%로 줄었다.
- 목표 전진 거리는 걷기 0.3m / 질주 0.8m로 줄였다. 능력치별 회전 한도, 회전 시 감속, 터치 간격, 헤비 터치 거리, 킥 준비 중 공 고정은 유지했다.
- 회전 도달 거리 경계, 몸만 돌리는 회복, 좌우 측면 공 접기, 앞선 간격의 속도 보정, 좌우 첫 터치 회귀 테스트를 추가했다. 기존 테스트의 기대값은 낮추지 않았다.

## 최종 검증

- `pnpm install`, `pnpm typecheck`, `pnpm build` 통과.
- `pnpm test`: 15개 파일, 172/172개 통과(신규 12개). 전체 실행 49.36초.
- 기존 5분 AI 경기 3시드 모두 종료, 헤비 터치 모두 0회, 최장 재개 대기 3.008초.
- 보조·수동·세미 패스는 각각 100/100, 이동 보조 none/low/high 받기는 각각 91/100으로 기존 기준 통과.
- `git diff --check` 통과. `.git/index.lock` 생성이 샌드박스에서 거부되어 커밋은 남기지 못했다. 푸시는 하지 않았다.
