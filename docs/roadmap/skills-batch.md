# 개인기 채우기 (지시서)

## 배경
개인기 틀은 끝났다: `src/gameplay/Skills.ts` (SkillDef 데이터, mirror, SkillInput 인식기, SkillRunner 실행기). 기준 개인기 5개(fake_shot, fake_pass, drag_back, feint_r/l)와 테스트 `tests/skills.test.ts` 를 먼저 읽고 같은 방식으로 늘린다.
- 커맨드 방향은 Shift(또는 Z)를 누른 순간의 몸 방향 기준 8방향 (F, FR, R, BR, B, BL, L, FL). 키보드 ↑ = 앞.
- 몸 동작은 `MOTION_CATALOG` 의 구운 클립 구간 재생 (kind: control 90개, trap 80개, turn 44개, shot/pass 등). 맞는 클립이 없으면 몸·공 궤적만으로 (기존 오버레이 회전 `rotateBone` 를 쓰지 말 것).
- 선수 별(`profile.skill`)이 모자라면 나가지 않는다 (같은 커맨드의 하위 개인기가 있으면 그것).
- 확인 도구: `scripts/skill-shots.mjs` (브라우저 캡처, 샌드박스에서 못 돌리면 "미실행"), `npx vite-node scripts/playground-run.ts`.

## 개인기 목록 (FC 온라인 키보드, 출처: 인벤 피파4 개인기 조작법 https://www.inven.co.kr/board/fifaonline4/4711/1535)
### 1차 (★2~3 + 패스)
| 별 | 개인기 | 커맨드 |
|---|---|---|
| ★2 | 스텝오버 오른쪽/왼쪽 | Shift + ↑↗→ / ↑↖← |
| ★2 | 리버스 스텝오버 | Shift + →↗↑ / ←↖↑ |
| ★2 | 사이드 스텝 | Shift + → 꾹 / ← 꾹 (누르는 동안 옆으로 공을 끌며 이동) |
| ★3 | 힐 플릭 | Shift + ↑↓ (탭) |
| ★3 | 볼 리프트 | Shift + ↑↑↑ |
| ★3 | 룰렛 (마르세유 턴) | Shift + ↓↙←↖↑↗→ / 반대 |
| ★3 | 페인트 후 반대로 | Shift + ←↙↓↘→ / →↘↓↙← |
| 패스 | 강한 땅볼 패스 Z+S, 낮은 로빙 Z+A, 강한 스루 Z+W | `docs/research/fc-mechanics.md` 참고. 기존 패스보다 빠르고 낮게, 정확도는 조금 낮게 |

### 2차 (★4~5, 저글링 제외)
멈춘 뒤 돌기(Shift + ↑←/↑→ 탭, ★4), 스핀(Shift + ↙↙/↘↘), 볼 롤 컷(Shift + ← 꾹, →), 엘라스티코(Shift + →↘↓↙←, ★5), 리버스 엘라스티코, 퀵 볼 롤(Shift + ↓ 꾹), 볼 롤 후 플릭(Shift + → 꾹, ↑ 탭), 엘라스티코 촙(Shift + ↓← / ↓→ 탭), 스핀 턴(★5, 같은 커맨드면 별 높은 쪽), 레인보우(Shift + ↓↑↑ 탭, ★4).
같은 커맨드가 여러 별 등급에 걸치면 별이 높은 선수에게 상위 개인기 (인식기가 이미 별 높은 쪽을 고른다 → 실행기에서 별이 모자라면 다음 후보로 내려가게 바꿀 것).

## 개인기마다 지킬 것
- 좌우 대칭은 mirror로.
- 공 궤적이 몸과 맞아야 한다: `contacts`(발이 공을 건드리는 시각)마다 해당 발끝과 공 거리가 0.25m 이하. 실제 GLB를 node에서 불러 확인하는 테스트(`tests/anim-smooth.test.ts`·`tests/motion.test.ts` 방식)를 개인기 전체에 대해 돌린다.
- 실제 키 입력 스크립트 테스트(개인기마다 1개): 해당 skill 이벤트가 정확히 1번, 소유 유지, 끝난 뒤 공·몸 방향이 의도대로.
- 커맨드끼리 오인식 테스트: 모든 개인기 커맨드를 정확히 입력했을 때 그 개인기만 나온다 (표로 전수 검사).
- AI도 가끔 쓴다: AI 소유자가 1:1에서 수비가 2m 안에 정면이면 별에 맞는 개인기를 낮은 확률로 (AI 대 AI 경기 기존 시뮬레이션 테스트 기대값을 낮추지 말 것).
- 개인기 이름·커맨드 목록을 `docs/skills.md` 에 표로 (조작 안내용).
