# 소리 믹스 결과

## 측정 방법

`ffmpeg`의 `ebur128=peak=true`로 통합 LUFS와 true peak를 측정했다. 0.4초 미만 단발 소리는 EBU R128 게이트 때문에 통합 LUFS가 유효하지 않아 표기하지 않았다. 기존 파일은 `HEAD`에 있는 버전, 변경 후 파일은 배포 파일이다. 단발 효과음은 디지털 피크 -3 dBFS를 목표로 했고, 관중 음원은 -23 LUFS를 목표로 했다. MP3 인코딩과 true peak 측정 때문에 표의 수치는 목표와 약간 다를 수 있다.

## 30초 경기 시뮬레이션

`tests/sound-mix.test.ts`에서 시드 17의 AI 경기 30초를 진행했다. 비교 위치는 경기장 중앙 `(0, 0)`이며, 이벤트를 내던 기존의 모든 터치 재생 요청과 선수별 0.28초 간격·속도·거리 판단을 적용한 재생 요청을 같은 이벤트 열에 대입했다. 기존 `Sound.play`의 키별 0.06초 중복 제한은 이 수치에 포함하지 않았다.

| 방식 | 30초 재생 요청 | 초당 요청 |
|---|---:|---:|
| 변경 전 (모든 터치) | 63 | 2.10 |
| 변경 후 | 25 | 0.83 |

관중 음원은 CC0 군중 대화 녹음의 서로 다른 구간이다. 실제 경기장 관중 녹음이 아니므로 환호의 현장감은 제한된다. 공 충격음도 Kenney의 일반 충격음을 사용했으며 축구공 현장 녹음은 아니다. 휘슬은 CC0 심판 휘슬 녹음의 속도를 조절한 짧은/긴 버전이다.
