# 2단계: 11대11 + 실제 규격 경기장

## 목표
1. **실제 규격 경기장** (IFAB): 105×68m, 골대 7.32×2.44m, 페널티 박스 16.5×40.32m, 골 에어리어 5.5×18.32m, 페널티 스팟 11m, 페널티 아크 반지름 9.15m(박스 밖 부분만), 센터 서클 9.15m, **코너 아크는 반지름 1m의 사분원(경기장 안쪽 부채꼴만)** — 지금은 원 전체가 그려져 있고 너무 큼. 라인 폭 12cm. 코너 플래그(깃대 1.5m 이상) 추가.
   - 지금 `src/environment/Stadium.ts`의 라인 그리기가 축소 경기장 기준이라 잘못된 부분(코너 원, 페널티 아크 각도, 골 에어리어 크기 등)을 모두 실제 규격으로.
   - 관중석·광고판·조명·그림자 카메라 범위를 새 크기에 맞춤.
2. **11대11**: 포메이션 4-3-3 (GK, LB, LCB, RCB, RB, LCM, CM, RCM, LW, ST, RW). `src/data/Formation.ts`에 슬롯 추가, 역할(풀백·윙어 포함)별 `TeamAI.formationTarget` 보정. 팀당 가상 선수 11명(능력치·주발·약발 포함, 포지션별 현실적 분포). 메뉴에 포메이션 선택(4-3-3, 4-4-2) 있으면 좋음.
   - 세트피스 배치(`SetPieces.ts`), 킥오프 배치, 대인 마크, 레이더, 스쿼드/능력치 메뉴, 이름 바가 11명에서 자연스럽게.
   - 카메라: 중계 카메라 높이/거리/FOV를 큰 경기장에 맞추고, 공 주변이 충분히 크게 보이게 (FC 기본 중계 카메라 느낌).
   - 경기 시간 표시/밸런스: 넓은 경기장에서 스태미너·AI 속도 재조정.
3. 성능: 22명 스킨드 캐릭터에서 데스크톱 60fps 유지 (필요하면 애니메이션 업데이트 LOD, 그림자 캐스터 제한).

## 완료 조건
- 테스트: 라인 좌표가 규격과 일치(단위 테스트), 11대11 AI 대 AI 5분에서 멈춤 없음, 슈팅·패스가 양 팀 모두 발생
- Playwright 스크린샷으로 중계 화면 확인 (코너 아크가 사분원인지 포함)
- `pnpm typecheck && pnpm test && pnpm build` 통과, 커밋 (푸시 금지)

## 참고: 브라우저 검증
Codex 샌드박스에서는 Chrome 실행이 막힌다(SIGABRT/EPERM). Playwright 스크립트는 `scripts/`에 작성만 하고, 실행이 막히면 재시도하지 말고 "미실행"으로 보고한다. 검증은 vitest 시뮬레이션 테스트로 대신한다. 브라우저 실행은 사람이 검토 단계에서 한다.
