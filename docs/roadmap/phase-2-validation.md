# 2단계 검증 기록

검증일: 2026-10-16. 환경: macOS arm64, Node 20.19.5, pnpm 9.15.9.

## 구현 범위

- 105×68m, 골문 안쪽 7.32×2.44m. 16.5×40.32m 페널티 박스, 5.5×18.32m 골 에어리어, 11m 스팟, 9.15m 센터 서클/페널티 아크, 반지름 1m 코너 사분원, 12cm 라인, 둥근 꼭대기의 1.6m 깃대.
- `src/data/PitchMarkings.ts` 좌표를 실제 잔디 캔버스와 단위 테스트가 함께 사용한다. 페널티 아크 각도는 박스 경계와 원의 교점으로 계산하고, 네 코너는 각각 안쪽 90°만 그린다.
- 규격 확인 출처: [IFAB Law 1](https://theifab.com/laws/latest/the-field-of-play/). 105×68m는 이 게임에서 선택한 경기장 규격이다.
- 4-3-3 (GK/LB/LCB/RCB/RB/LCM/CM/RCM/LW/ST/RW), 팀당 가상 선수 11명, 기존 선수 프로필 보존 및 12명 추가. 풀백·윙어 OVR 가중치 추가.
- 윙어 폭·풀백 오버랩·중앙/측면 미드필더 지원 위치 분리, 마크 범위 제한. 전진 패스 선호·막힌 길목을 넘기는 로빙으로 중앙 패스 반복을 수정했다.
- 킥오프는 ST만 중앙, 코너는 9개의 서로 다른 공격 대기 지점, 골킥 상대는 박스 밖. 스로인 근처 수비도 서로 다른 위치에 배치한다.
- 스쿼드는 카드 그리드로 22명 모두 접근 가능. 능력치 선택·이름 바·레이더는 기존의 선수 배열 순회를 유지한다. 경기 시간은 기존 2/4/6/8분 설정을 90분으로 환산한다.
- 중계 카메라는 높이 25m·공 뒤 38m·FOV 42°로 공을 따라가며 터치라인에서도 시야 크기를 유지한다. 경기장 기준 광고판·관중석·조명 위치가 확장되고 그림자 카메라는 필드 대각선 반경을 덮는다.
- 스태미나 소모/회복은 0.045/0.025초당, 양 팀 AI 속도 배율 1. 공에서 32m 이상 떨어진 선수의 평상시 애니메이션만 30Hz로 줄이고 위치·액션은 매 프레임 갱신한다. 24m 안 선수만 그림자를 만든다.

### 기존 기능 회귀

- 패스: 보조 45° 입력, 수동, 세미 각각 **100/100**. 이동 입력 중 받기는 이동 보조 없음/낮음/높음 각각 **91/100** (기준 ≥90%).
- 실제 궤적 유효슈팅: ST **395/400**, CB **332/400**. 골문 확대 후 수치이며 기존 정확도/능력치 차이 기준을 통과했다.
- 실제/아케이드 2m 낙하 반발: **0.676 / 0.886m**. 경사로 구름: **7.917 / 4.727m**. 아케이드 10m/s 정지 거리 **23.439m**.
- 키보드 4개·터치 39개·터치 DOM 12개 통과. 보정 설정·물리 프리셋 코드는 변경하지 않았다.
- 테스트 배경 선수는 새 경기장 외곽에 배치하고, 기존 CM/CB 대상은 새 인덱스 대신 포지션으로 찾는다. 슛 거리는 기존과 같은 골문 앞 7m를 유지한다. 기존 성공 임계값은 낮추지 않았다.

## 브라우저 및 성능: 미실행

`pnpm dev --host 127.0.0.1`는 5180 포트에서 실행됐다. `pnpm test:browser`를 한 번 시도했으나 Playwright 캐시의 Chrome for Testing (chromium-1234)이 시작 직후 **SIGABRT**로 종료됐고 `kill EPERM`이 기록됐다. 페이지 열기 전 실패하여 스크린샷·브라우저 assertion·FPS 측정은 실행되지 않았다. 로드맵 지시에 따라 재시도하지 않았다.

`pnpm test:phase2`용 `scripts/phase-2-smoke.mjs`를 작성하고 구문 검사를 통과했다. 실행 가능한 환경에서:

```bash
pnpm dev
# 별도 터미널
pnpm test:browser
pnpm test:mobile
pnpm test:phase2
```

마지막 명령은 1440×900/DPR 1에서 실제 스킨드 선수 22명을 확인하고 3초 워밍업 후 10초의 평균 FPS·p95·최대 프레임 시간을 측정한다. `.artifacts/phase-2/`에 중계/전체 경기장/네 코너 스크린샷과 `report.json`을 남긴다. 60Hz 환경 타이머 오차를 감안해 평균 ≥55fps, p95 ≤25ms를 자동 기준으로 사용한다. 이는 60fps 유지의 실측 증거를 대신하지 않으므로 하드웨어·브라우저·전원 모드와 함께 결과 및 육안 부드러움을 검토해야 한다.

## 커밋: 환경 권한으로 미완료

첫 의미 단위의 `git add src/config.ts src/data/PitchMarkings.ts src/entities/Goal.ts src/environment/Stadium.ts src/camera/CameraRig.ts`가 다음 오류로 실패했다.

```text
fatal: Unable to create '.../snapshoot-classic/.git/index.lock': Operation not permitted
```

`.git`은 이 세션에서 읽기 전용이다. 인덱스/커밋 생성 권한을 우회하지 않았고 푸시는 실행하지 않았다. 변경 파일은 작업 트리에 남아 있다. `.artifacts/phase-2-commits/`에 구현·회귀 테스트 / 브라우저 검증·문서의 두 단위로 패치와 커밋 메시지를 저장했다. 두 메시지 모두 지정된 `Co-Authored-By: Codex <noreply@openai.com>` 트레일러를 포함한다. 이 파일들은 Git 추적 대상이 아닌 로컬 전달용 아티팩트다.
