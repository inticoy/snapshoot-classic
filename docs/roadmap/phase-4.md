# 4단계: 축구 규칙

## 목표 (IFAB 경기 규칙을 게임에 맞게 단순화)
- **파울**: 뒤에서의 태클, 공보다 사람을 먼저 친 태클(늦은 태클), 슬라이딩 위험도. 태클 각도·속도·공 접촉 여부로 판정. 어드밴티지(공격팀이 계속 유리하면 진행, 2초 후 판정 확정) 간단 구현.
- **프리킥**: 파울 지점. 직접 프리킥. 수비 벽(9.15m, 위험 지역에서 인원 자동), 키커 조작: 방향키 조준 + D 슛(감아차기 Z+D), S/A 패스. AI 키커.
- **페널티킥**: 박스 안 파울 → PK. 키커 조준(방향키 + 파워), 키퍼 다이빙(사용자 수비 시 방향키로 다이빙 방향 선택, AI는 능력치 기반 예측). 다른 선수는 박스 밖. SnapShoot 승부차기와 나중에 합칠 수 있게 PK 로직을 모듈로 분리.
- **카드**: 파울 심각도로 옐로/레드. 옐로 2장 = 퇴장. 퇴장 시 인원 감소, HUD 표시, 경기 기록에 반영.
- **전·후반 + 진영 교체 + 추가 시간**: 하프타임 화면(경기 기록), 후반 진영 교체(카메라·조작 방향 정상), 추가 시간 표시(+n).
- **오프사이드**: 패스 순간 판정, 부심 깃발 연출(간단), 간접 프리킥으로 재개.
- **키퍼 백패스 규칙**: 동료가 발로 의도적으로 준 공은 손으로 못 잡음 (간접 프리킥 대신 단순히 손 사용 금지).
- **무승부 시 승부차기** 옵션 (메뉴 설정).
- 심판 휘슬 종류 구분, 티커 메시지(파울, 오프사이드, 카드).

## 완료 조건
- 테스트: 뒤에서 태클 → 파울+프리킥, 박스 안 → PK, 오프사이드 위치 패스 → 오프사이드, 하프타임 후 진영 교체, 옐로 2장 → 퇴장
- AI 대 AI 장시간 시뮬레이션에서 멈춤 없음, 파울/오프사이드가 과하지 않음(90분 환산 각 0~25회)
- `pnpm typecheck && pnpm test && pnpm build` 통과, 커밋 (푸시 금지)
