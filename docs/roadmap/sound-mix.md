# 소리 다듬기 (지시서)

## 사용자 피드백
1. 소리 크기 차이가 너무 크다.
2. 드리블할 때 공이 너무 자주 닿아 "토도도도독" 소리가 난다.
3. 더 완성도 높은 소리가 있으면 찾아서 바꿔 달라.

## 현재 상태 (실측, ffmpeg ebur128 통합 음량)
| 파일 | LUFS |
|---|---|
| bounce.mp3 | -33.9 |
| kick.mp3 | -33.9 |
| post.mp3 | -27.6 |
| net.mp3 | -21.6 |
| chant.mp3 | -20.9 |
| save.mp3 | -20.4 |
| cheer.mp3 | -16.7 |
| goal.mp3 | -16.6 |
- 재생: `src/audio/Sound.ts` (`play(key, volume, rate)`), 호출: `src/core/Game.ts` `handleEvents` (touch 453줄, kick 456줄 …).
- 출처·라이선스 기록이 없는 파일들이다 (최초 커밋부터 있음).

## 할 것
1. **소리 교체 (출처가 확실한 것만)**: CC0 우선 (Kenney, freesound.org CC0 필터, OpenGameArt CC0, Sonniss GDC 번들처럼 게임 사용이 명시적으로 허용된 것). 공 차기(강·약 여러 개), 드리블 터치(부드러운 발등 터치 3~4종), 바운드, 골대, 그물, 선방, 관중(웅성임·환호·골), 휘슬(짧게·길게·세 번)을 찾는다.
   - 받은 원본은 `public/assets/audio/` 에 mp3(모노, 짧게 자르기, 앞 무음 제거)로 넣고 `public/assets/audio/LICENSE.md` 에 파일별 출처 URL·작성자·라이선스를 적는다.
   - 출처·라이선스를 확인할 수 없으면 쓰지 않는다. 실제 리그/방송 녹음 금지.
   - 휘슬이 지금 없다면 이벤트(킥오프·전후반 종료·반칙·오프사이드)에 연결한다.
2. **음량 맞추기**: 모든 효과음 파일을 같은 기준(예: 단발 효과음 피크 -3 dBFS, 관중 루프 -23 LUFS)으로 정규화하는 스크립트 `scripts/normalize-audio.mjs` (ffmpeg 사용). 그 위에서 `Game.ts` 의 볼륨 계수를 카테고리별로 정리(공 소리 / 몸 / 관중 / 휘슬)하고, `Sound.ts` 마스터에 `DynamicsCompressorNode` 를 둬 겹칠 때 튀지 않게.
3. **드리블 터치 소리**:
   - 모든 터치에 소리를 내지 않는다: 같은 선수 최소 간격(예: 0.28초), 공 속도 1.2 m/s 미만 터치(발바닥 세우기)는 무음 또는 아주 작게.
   - 걷기 터치는 작고 둔하게, 질주 치고 나가기는 조금 크게. 샘플 3~4개 랜덤 + 피치 ±6%.
   - 화면 밖/먼 선수(카메라에서 25m 이상) 터치는 줄이거나 생략.
4. 설정 메뉴의 소리 크기(있으면)와 충돌하지 않게.

## 완료 조건
- vitest: 소리 재생 판단 로직을 순수 함수로 빼서 테스트 (터치 간격 제한, 속도별 볼륨, 거리 감쇠, 카테고리 볼륨 범위). AudioContext 없는 환경에서도 테스트 통과.
- 정규화 후 각 파일 LUFS/피크 표를 보고서에 (전/후).
- 30초 경기 시뮬레이션에서 초당 터치 소리 횟수 (전/후) 보고.
- `pnpm typecheck && pnpm test && pnpm build`.
