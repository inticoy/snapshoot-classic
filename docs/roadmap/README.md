# 로드맵 (우선순위 순)

| 단계 | 내용 | 이유 |
|---|---|---|
| 0 | 테스트 기반 + 메타정보 | 이후 모든 단계의 자동 검증. 공개 사이트 공유/파비콘 |
| 1 | 터치 조작 (모바일) | 공개 링크를 휴대폰으로 열면 플레이 불가 |
| 2 | 11대11 + 실제 규격 경기장/라인 수정 | 오프사이드·세트피스 배치의 전제 |
| 3 | 키퍼 1대1 + 키퍼 물리 | 페널티킥의 전제, 수비 품질 |
| 4 | 축구 규칙 (파울·프리킥·PK·카드·전후반·오프사이드·백패스) | 게임 흐름 완성 |
| 5 | 등번호·이름·얼굴 | 연출 |
