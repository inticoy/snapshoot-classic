# 0단계: 테스트 기반 + 메타정보

## 목표
1. **브라우저 없이 경기 시뮬레이션을 테스트**할 수 있게 한다.
   - vitest 추가 (`pnpm test`). `Match`를 Node에서 만들 수 있도록 렌더 의존(캔버스 텍스처, GLTF 로드, document)을 분리하거나 주입한다. 게임 동작은 바뀌면 안 된다.
   - 고정 시드 난수(`src/core/Random.ts` 등)로 `Math.random`/`gauss` 사용처를 바꿔 재현 가능한 테스트를 만든다.
   - 최소 테스트 (각각 의미 있는 수치 범위로 단언):
     - 물리: 2m 낙하 반발 높이(실제·아케이드 모두 0.6~1.0m), FIFA 경사로 구르기(3.43 m/s 출발, 4~10m), 10 m/s 땅볼 정지 거리(아케이드 18~28m)
     - 패스: 보조 설정에서 45° 어긋난 입력도 동료에게 도달(≥ 90%), 수동은 정확한 방향/세기면 도달
     - 받기: 방향키를 공 쪽으로 누른 채로도 받는다(≥ 90%)
     - 슛: 골 결정력 높은 공격수가 수비수보다 유효슈팅 비율이 높다
     - 세트피스: 터치라인 아웃 → 스로인, 수비팀 마지막 터치 골라인 아웃 → 코너킥, 공격팀 → 골킥
     - 장시간: AI 대 AI 5분 시뮬레이션에서 어떤 단계도 10초 이상 멈추지 않는다
   - GitHub Actions 배포 워크플로에 build 전 `pnpm typecheck && pnpm test` 추가 (실패 시 배포 중단).
2. **메타정보**: 파비콘(SVG, 공 모양 간단한 아이콘), `og:title`/`og:description`/`og:image`(1200×630 스크린샷 이미지를 `public/`에 생성해 커밋), `twitter:card`, `theme-color`, `apple-touch-icon`, `manifest.webmanifest`. 설명 문구는 한국어.

## 완료 조건
- `pnpm typecheck && pnpm test && pnpm build` 통과, 테스트 10개 이상
- 개발 서버에서 기존처럼 게임이 정상 동작 (메뉴 → 경기 시작 → 골)
- 커밋 (푸시 금지)
