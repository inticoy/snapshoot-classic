# 3단계: 키퍼 1대1 + 키퍼 물리

## 목표
- 스루 패스/단독 돌파 상황에서 키퍼가 **각도를 좁히며 전진**, 적절한 순간 **발밑으로 몸을 던져(smother)** 공을 덮치거나 슬라이딩. 너무 일찍 나오면 칩슛에 당하고, 늦으면 실점하는 트레이드오프. GK 위치 선정·반응 속도·다이빙 능력치 반영.
- 키퍼 몸을 cannon 물리 바디(캡슐/박스 조합, 다이빙 시 자세에 따라 이동/회전)로 만들어 **공이 몸에 맞고 튕기는 블록**을 물리로 처리. 기존 확률 선방 판정과 자연스럽게 공존(손이 닿는 범위는 선방 판정, 몸통은 물리 충돌).
- 크로스 처리: 키퍼가 박스 안 높은 공에 나와서 펀칭/캐치 (거리·혼잡도 판단).
- 사용자 키퍼 조작 기본: 상대 공격 중 `W`(키보드)로 키퍼 돌진 지시 (FC 온라인 키퍼 W 돌진).
- 키퍼 애니메이션: 전진 자세, 발밑 다이빙(옆으로 누움) 오버레이.

## 완료 조건
- 테스트: 1대1 시나리오(골대 25m 앞 단독 드리블) 다수 시뮬레이션에서 키퍼가 전진하고, 득점률이 30~60% 범위. 칩슛 성공률이 키퍼가 나와 있을 때 더 높음. 몸통 블록 이벤트 발생.
- 회귀 없음, `pnpm typecheck && pnpm test && pnpm build` 통과, 커밋 (푸시 금지)
