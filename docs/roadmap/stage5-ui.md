# 5단계: 메뉴 레이아웃·모바일 (지시서)
사용자 피드백: "스쿼드처럼 우측에 내용이 많은 메뉴는 전체 메뉴 레이아웃이 크게 바뀜. 좌측 메뉴 위치는 고정되어야 함. 모바일에서도 높이가 너무 길어 안 맞음."
1. 메뉴(`src/ui/Menu.ts`, `src/theme.css`): 왼쪽 메뉴 열은 고정 폭·고정 위치(어떤 탭을 골라도 x/y가 같다). 오른쪽 내용 영역은 고정 크기 + 자체 스크롤.
2. 모바일(가로 844×390, 세로 390×844): 메뉴가 화면 높이를 넘지 않게 — 내용 스크롤, 필요하면 왼쪽 메뉴를 위쪽 탭 줄로.
3. 모바일 개인기 스틱 (`docs/CHECKLIST.md` 메모): 오른쪽 아래에 개인기 스틱 — 누른 채 굴리면 8방향 순서가 `SkillInput`의 shift 모드 입력으로 들어간다(`Input`에 touch 개인기 축 추가, `TouchControls`). 탭 = 짧게, 길게 유지 = 꾹.
4. 검증: Playwright로 데스크톱·모바일 가로·세로에서 메뉴 탭마다 왼쪽 메뉴 위치가 동일(픽셀 좌표 비교)하고 메뉴가 뷰포트 안에 있는지 `scripts/menu-smoke.mjs`. jsdom 테스트로 개인기 스틱이 스텝오버를 인식하는지. `pnpm typecheck && pnpm test && pnpm build`. AGENTS.md 규칙.
