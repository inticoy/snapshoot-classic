# 3단계: FC 온라인 커맨드 채우기 (지시서)

근거: `docs/roadmap/fc-parity-plan.md` 2단계, `docs/research/fc-commands.md` 표. 입력은 `src/core/Input.ts`(ACTION_KEYS), 처리는 `src/gameplay/Match.ts` `handleUser`, 킥 계산은 `src/gameplay/Kicks.ts`, 상수는 `src/config.ts`.
더블탭 판정 창은 `config.ts`에 `INPUT.doubleTap = 0.25`(초) 같은 상수로. 사용자 입력 기준(키보드)으로 구현하고 AI는 손대지 않는다.

## 패스
- **SS 딩크 패스**: S를 0.25초 안에 두 번 → 공을 살짝 띄워(최고 높이 0.6~0.9m) 앞 수비수의 발·태클을 넘기는 짧은 패스. 지면 패스와 같은 수신자 선택, 속도는 S의 0.9배, 첫 바운드가 수비수 뒤.
- **WW 딩크 스루**: 같은 방식의 스루.
- **Z+Q+W 낮은 로빙 스루**: 로빙 스루(Q+W)보다 낮고 빠르게 (최고 높이 1.5~2.5m, 체공 짧게).
- **Q+S 침투 패스**: 받는 선수가 뛰어들 앞 공간으로 짧게 (스루보다 리드 짧고 땅볼).
- **C+S 플레어 패스**: 아웃프런트 연출(동작만 다르게, 정확도 약간 낮음, 개인기 별 3 이상).
- **크로스** (상대 박스 근처 측면, |z| > 박스 폭/2 그리고 상대 골 30m 안에서 A 계열): A 기본 / A+A 낮은 / Q+A 높은 / C+A 플레어 / Z+A 빠른(강하고 낮게).

## 슛
- **D+D 드리븐 슛**: D를 두 번 → 낮고 강하게 깔아 차기(수직 속도 작게, 파워 +10%, 정확도 약간 낮음).
- **Z+D+D 감기는 드리븐**: 드리븐 + 약한 감아차기.
- **C+D 플레어 슛**: 아웃프런트/라보나 연출, 정확도 낮음.
- **F+D+D 파워슛**: F 키 추가(ACTION_KEYS `power: ['KeyF']`). F 누른 채 D 게이지 → 다시 D. 준비 동작 길게(0.4초 windup), 매우 강함. 머리 위 게이지의 초록 구간(타이밍 창 0.1초)에 두 번째 D를 맞추면 정확도 보너스. HUD에 간단한 타이밍 막대.

## 수비
- **Space 유지**: 공 가진 상대에게 붙어 당기고 버티기(상대 속도 -30%, 1.5초 넘게 유지 시 파울 확률↑ — `Rules.judgeTackle` 재사용).
- **D (수비, 공이 자유로울 때)**: 걷어내기 — 가까운 루즈볼을 멀리 높게 차 낸다. 공 가진 상대 옆에서 탭 = 밀치기(몸싸움 능력치 비교, 성공 시 상대 균형 상실 0.3초).
- **C+방향 몸싸움**, **C+E 달리며 견제**: 견제(C) 중 E를 누르면 속도 0.95 유지.

## 검증 (필수)
- 각 커맨드마다 플레이그라운드 JSON 스크립트(`src/playground/Script.ts`, `runScript`) 실제 키 입력 테스트: 의도한 킥 종류/결과(높이·속도·리드)가 나오고, 비슷한 다른 커맨드와 헷갈리지 않음(S 한 번 vs SS, D vs DD 등).
- 기존 테스트 기대값을 낮추지 말 것. `pnpm typecheck && pnpm test && pnpm build`.
- 보고서 `docs/roadmap/stage3-results.md`: 커맨드별 측정 표(초속, 최고 높이, 수신자, 성공률).
