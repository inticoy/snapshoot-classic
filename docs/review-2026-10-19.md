## 멀티플레이
- [x] (높음) 방장 물리 설정이 실제 물리 월드에 적용되지 않음 → 경기 어긋남
- [x] (높음) 파워슛(F)·키보드 킥 표시·짧은 탭이 전송되지 않음
- [x] (높음) 재접속 따라잡기 뒤 경기가 영원히 멈출 수 있음
- [x] (높음) 동기화 복구가 무한 새로고침에 빠질 수 있음 → 2회 제한
- [x] (높음) 방 코드만 알면 끊긴 자리를 차지할 수 있음 → 자리별 비밀값
- [x] (높음) 잘못된 패킷이 수신 처리를 멈춤 → 서버·클라이언트 검증
- [x] (높음) 내 연결이 끊기면 안내 없이 멈춤 → 안내 후 재연결
- [x] (요청) 일시정지 시 둘 다 멈춤, 1인 3회·60초 제한, 시간 지나면 자동 재개
- [x] (요청) 핑 표시 (오른쪽 위, 2초마다 측정, 색으로 상태)
- [x] (중간) 재접속 기록을 다 받기 전에 새 입력이 섞임 → resumeEnd 뒤 진행, 서버가 겹친 틱 버림
- [x] (중간) 반쯤 열린 옛 연결이 자리를 막음 → 비밀값이 맞으면 옛 연결 교체
- [x] (중간) 따라잡는 동안 지난 골 소리·배너가 한꺼번에 나옴
- [x] (중간) 원정 화면 이름 표시가 상대 대신 자기 팀
- [x] (중간) 빠른 매칭 소켓이 닫혀도 무한 대기
- [x] (낮음) 왕복 시간 조작으로 입력 지연을 키울 수 있음 → 400ms 상한
- [x] (요청) 멀티에서 공이 안 뺏김 → 몸싸움 뺏기 추가 (멈추거나 천천히 끄는 공)
- [x] (중간) 입력 지연 여유가 2틱뿐이라 지터에 자주 멈춤 → 여유 늘리기·경기 중 조정

- [x] (중간) 방장이 고른 경기 시간이 온라인에 적용되지 않음
- [ ] (낮음) 상태 해시 범위가 좁음 (난수 상태·타이머 빠짐)

## 게임플레이
- [x] (요청) F+D 파워 게이지: D 먼저 누르고 F를 눌러도 파워슛
- [x] (요청) 타이밍 게이지를 빨주노초노주빨 그라데이션으로
- [x] (요청) Shift 짧게 = 짧은 치달 (EE보다 짧게, 질주 없이도)
- [x] (요청) 마르세유 등 큰 회전 커맨드가 키보드로 안 나감 → 대각선 생략 허용
- [x] (요청) ← ↖ ↑ ↗ → 로 굴리면 헛다리가 이어서 나감, 개인기 중 다음 커맨드 예약
- [x] (요청) Shift+방향 선수 변경이 달리던 방향으로는 안 됨
- [x] (요청) 가만히 공을 끼고 있어도 붙은 상대가 못 뺏음
- [x] (요청) 공을 받기 전에 누른 패스·개인기가 안 나감 (뺏기면 취소)
- [x] (요청) 떨어진 공에 슛하면 달려가 차지 않고 공이 순간이동
- [x] (요청) Q·QS 등 침투 지시 없음 (끝까지 뛰지 않고 적당히 멈추게)
- [x] (요청) 내가 멈춰 있으면 주변 AI도 멈춤 → 확인 결과 오프라인은 압박함, 온라인은 상대 사람이 조작 중이라 압박 안 함. 재현 조건 확인 필요 → 멈춘 공 몸싸움 뺏기 추가
- [x] (높음) 개인기 시범이 실제 별과 다른 속도로 재생 (5성 강제)
- [x] (중간) 개인기 실패 이유·입력 중인 방향을 보여 주지 않음
- [x] (중간) 개인기를 수비수 상대로 시험할 상황 없음
- [x] (중간) 대각선으로 달리다 Shift를 누르면 탭 커맨드가 실패할 수 있음 (기준 방향 스냅 불일치)
- [x] (중간) 키보드 단타 패스·슛이 더블탭 판정 때문에 최대 0.25초 늦음
- [x] (중간) 모바일에서 Z 계열 개인기(드래그백 등)를 낼 수 없음
