# 개인기·Z 패스 조작 안내

방향은 Shift 또는 Z를 누르는 순간 선수의 몸 방향을 기준으로 한다. ↑는 앞, →는 오른쪽이다. 대각선은 방향키 두 개를 함께 누른다. 연속된 ↑↑↑는 사이마다 방향키를 떼어 세 번 탭한다.

탭은 0.3초 미만, 꾹은 0.3초 이상이다. 방향을 바꾼 뒤 0.12초 쉬거나 보조키를 떼면 커맨드를 확정한다. 입력 사이가 0.45초 넘게 끊기면 새 커맨드로 시작한다. 선수의 개인기 별이 부족하면 발동하지 않으며 같은 커맨드의 하위 기술이 있으면 그 기술을 쓴다.

| 별 | 개인기 | 커맨드 |
|---|---|---|
| ★1 | 페이크 슛 | D 게이지 중 S (또는 Z+C+D) |
| ★1 | 페이크 크로스 | A 게이지 중 S |
| ★2 | 드래그백 | Z+↓ |
| ★2 | 오른쪽 속임 동작 | Shift+→ 탭 |
| ★2 | 왼쪽 속임 동작 | Shift+← 탭 |
| ★2 | 오른쪽 스텝오버 | Shift+↑↗→ |
| ★2 | 왼쪽 스텝오버 | Shift+↑↖← |
| ★2 | 오른쪽 리버스 스텝오버 | Shift+→↗↑ |
| ★2 | 왼쪽 리버스 스텝오버 | Shift+←↖↑ |
| ★2 | 오른쪽 사이드 스텝 | Shift+→ 꾹 |
| ★2 | 왼쪽 사이드 스텝 | Shift+← 꾹 |
| ★3 | 힐 플릭 | Shift+↑↓ 탭 |
| ★3 | 볼 리프트 | Shift+↑↑↑ 탭 |
| ★3 | 오른쪽 룰렛 | Shift+↓↙←↖↑↗→ |
| ★3 | 왼쪽 룰렛 | Shift+↓↘→↗↑↖← |
| ★3 | 왼쪽 페인트 후 오른쪽 | Shift+←↙↓↘→ |
| ★3 | 오른쪽 페인트 후 왼쪽 | Shift+→↘↓↙← |

사이드 스텝은 Shift와 옆 방향을 누르는 동안 공을 옆으로 끌며 계속 이동한다. 방향키나 Shift를 놓거나 방향을 바꾸면 끝난다. 페이크 슛·페이크 크로스·드래그백은 종료할 때 방향을 누르고 있으면 그 방향으로 나간다.

| 패스 | 커맨드 | 효과 |
|---|---|---|
| 강한 땅볼 | Z+S | 기본 땅볼보다 수평 속도 25% 증가, 초기 수직 속도 0.12m/s |
| 낮은 로빙 | Z+A | 기본 로빙의 비행시간 계산값 72%, 수평 속도 약 39% 증가 |
| 강한 스루 | Z+W | 기본 스루보다 수평 속도 25% 증가, 초기 수직 속도 0.12m/s |

Z 패스 3종은 방향 오차가 15% 늘어난다. 보조·세미·수동 보정과 약발·압박·능력치 효과는 적용된다. Q+W 로빙 스루, Z+D 감아차기, Q+D 칩슛도 사용할 수 있다. 수비 상황의 기존 키 배치는 유지된다.

1차(★2~3와 Z 패스)와 아래 2차(★4~5 일부)가 구현돼 있다. 저글링은 아직 없다. 구현·접촉 측정 결과는 [검증 보고서](roadmap/skills-batch-results.md)를 참고한다.

## 2차 (★4~5)
| 별 | 개인기 | 커맨드 | 비고 |
|---|---|---|---|
| ★4 | 멈춘 뒤 오른쪽/왼쪽으로 돌기 | Shift + ↑→ / ↑← (탭) | ★5 선수는 같은 커맨드로 스핀 턴 |
| ★5 | 스핀 턴 | Shift + ↑→ / ↑← (탭) | 멈추지 않고 더 빠르게 빠져나간다 |
| ★4 | 스핀 | Shift + ↘↘ / ↙↙ (탭) | 발바닥으로 끌며 반 바퀴 |
| ★4 | 레인보우 | Shift + ↓↑↑ (탭) | 공이 머리 위로 넘어간다 |
| ★5 | 엘라스티코 | Shift + →↘↓↙← | ★3·4 선수는 같은 커맨드로 '오른쪽 페인트 후 왼쪽' |
| ★5 | 리버스 엘라스티코 | Shift + ←↙↓↘→ | ★3·4 선수는 '왼쪽 페인트 후 오른쪽' |
| ★5 | 엘라스티코 촙 | Shift + ↓→ / ↓← (탭) | |
| ★5 | 퀵 볼 롤 | Shift + ↓ 꾹 | |

페이크: 달리는 중 A·D 게이지 중 S = 달리며 페이크 (별이 높을수록 빠르다), 멈춰 있거나 C를 같이 누르면(C+A+S) 제자리 헛발질.
| ★4 | 볼 롤 컷 | Shift + ← 꾹 → (사이드 스텝 중) → 짧게 / 반대 | 옆으로 끌던 공을 몸 앞으로 굴려 대각선으로 |

감아차기(Z+D)는 약발 3 이하면 공을 주발 쪽으로 옮겨 주발로 찬다 (휘는 방향 = 차는 발).
아직 없음: 볼 롤 후 플릭, 저글링 계열.
