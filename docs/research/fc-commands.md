## 2. 개인기 방향 기준 (가장 중요)

**결론: 키보드 방향키 자체는 화면(절대) 방향이고, 개인기 커맨드는 "선수가 보는 방향"에 따라 회전시켜 입력한다.** 흔히 쓰는 표기 'Shift + ↓↙←↖↑↗→'(오른쪽 룰렛)는 **선수가 화면 ↑을 보고 있을 때**의 입력이다.

근거: 인벤 개인기 DB는 키보드 커맨드를 '보는 방향' ↑ / ↓ / → / ← 4개 열로 나눠 따로 적는다 (https://fifaonline4.inven.co.kr/dataninfo/sklmv/). 예시:
- 오른쪽 마르세이유 룰렛 ★3: ↑ 볼 때 `SHIFT + ↓↙←↖↑↗→`, ↓ 볼 때 `SHIFT + ↑↖←↙↓↘→`, → 볼 때 `SHIFT + ←↙↓↘→↗↑`, ← 볼 때 `SHIFT + →↗↑↖←↙↓`
- 드래그 백 ★2: ↑ 볼 때 `Z + ↓`, ↓ 볼 때 `Z + ↑`, → 볼 때 `Z + ←`, ← 볼 때 `Z + →`
- 오른쪽 스텝오버: ↑ 볼 때 `SHIFT + ↑↗→`, → 볼 때 `SHIFT + →↘↓`

정리하면 ↑열은 선수 기준 "앞 = ↑" 정규형이다. 구현 방법: 선수 heading 기준으로 입력 방향을 로컬 좌표(앞/뒤/좌/우)로 변환한 뒤 정규형 패턴과 매칭하면 된다. 단 → 열은 정확한 90° 회전(↑→ 를 →↓ 로)이 아니라 일부 칸이 DB 오기로 보인다(예: 퀵 볼 롤 ← 열 'SHIFT + 유지 ↓'). 4방향만 적혀 있어서 대각선을 볼 때의 처리는 **미확인**이다.

EA 엔진 쪽 근거(패드 R스틱): "Right Stick directions are always relative to the direction your player is facing, not the camera." (games.gg, FC 27 가이드). EA 공식 매뉴얼(EA20)에서는 같은 문장을 찾지 못했다.

## 3. FIFA 엔진 동작 메모 (EA 출처, 패드 기준)

- 쉴드/견제: "Shield/Jockey: L2 button (hold)". 공을 가진 쪽은 몸으로 공 지키기, 수비 쪽은 견제가 된다. 즉 같은 키가 상황에 따라 다르다. FC온라인에서 수비 견제는 C 유지라서, 공격 시 C 단독이 키핑일 가능성이 있다(**추정**). 원문: "Engage shielding opponent: L2 + left stick (towards shielding dribbler)" [EA20]
- 견제/러닝 견제: "Jockey/ Grab and hold: L2 (hold)", "Running jockey: L2 + R2 (hold)" → FC온라인 C / C+E에 대응 [EA20]
- 컨테인: "Contain: Cross (hold)", "Teammate contain: R1 (hold)" → FC온라인 D 유지(압박) / Q 유지(지원 요청)에 대응 (**추정 매핑**) [EA20]
- 녹온/퍼스트터치: "First touch/ Knock-on: R2 + right stick", "Disguised first touch: R1 (hold) + left stick (towards ball)", "Set up touch: R1 + right stick (hold in direction)" [EA20]
- 원투: EA20에 이름으로 나오는 항목 없음. 가장 가까운 것은 "Pass and go: L1 + Cross"(패스 후 침투). FC온라인 키보드 대응키는 **미확인**.
- 드리븐 변형: "Driven ground pass: R1 + Cross", "Driven lob pass/Cross: R1 + Square", "Driven lobbed through pass: L1 + R1 + Triangle" → FC온라인 Z(=R1)+S, Z+A, Z+Q+W와 일치. Z=R1, Q=L1 대응으로 보임 (**추정**) [EA20]
- 선수 변경: "Change player: L1", "Change player (manual): right stick" → FC온라인 S / Shift+방향 [EA20]
- 세트피스: "Corners pass: Cross / lob cross: Square", "Short throw in: Cross / Long throw in: Cross (hold)/Square" [EA20]
